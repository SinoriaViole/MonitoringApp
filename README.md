# Monitoring App

**Monitoring App** is an Android application designed to support monitoring activities between Parent and Child users through an integrated mobile platform.

The application uses Firebase services to support user authentication, data management, and communication between users.

## ✨ Features

- **User Authentication** — User authentication using Firebase Authentication.
- **Parent & Child Roles** — Supports Parent and Child user roles.
- **User Relationship Management** — Connects Parent and Child accounts using the registered parent email.
- **Cloud Database** — Stores and manages application data using Cloud Firestore.
- **Push Notifications** — Firebase Cloud Messaging (FCM) integration for notifications. *(Include this feature if implemented in the repository.)*

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/SinoriaViole/MonitoringApp.git
   ```

2. Open the project using Android Studio.
3. Configure the Firebase project and add the required `google-services.json` file.
4. Sync Gradle dependencies.
5. Build and run the application on an Android device or emulator.
